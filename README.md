Build a React Shopping Cart application by following the design and functionality of the reference website. The application should provide a simple and responsive shopping experience using React components and hooks. Requirements  Display products in a grid layout.  

 Show product image, name, price, and category.  

 Add products to the shopping cart.  

 Increase/decrease product quantity.  

 Remove products from the cart.  

 Display the total number of items and total cart price.   Use reusable React components and React Hooks (useState).  

 Responsive design for desktop and mobile devices.  


# React Shopping Cart Application:
A simple, responsive shopping cart application built using React and modern CSS.

## Features
- **Product Display**: Displays products in a clean grid layout with images, title, price, and category.
- **Cart Management**: Add items to the cart, adjust item quantities, and remove items dynamically.
- **Real-time Totals**: Automatically updates and displays the total item count and total cart price.
- **Responsive Layout**: Designed to work smoothly on mobile, tablet, and desktop viewports.

## Tech Stack
- React.js
- JavaScript (ES6+)
- CSS3 (Flexbox & Grid)
- Vite
