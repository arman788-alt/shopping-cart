# React Shopping Cart Application

A simple, responsive shopping cart application built using React and modern CSS.

## Features
- **Product Display**: Displays products in a clean grid layout with images, title, price, and category.
- **Cart Management**: Add items to the cart, adjust item quantities, and remove items dynamically.
- **Real-time Totals**: Automatically updates and displays the total item count and total cart price.
- **Responsive Layout**: Designed to work smoothly on mobile, tablet, and desktop viewports.

## Tech Stack
- React.js
- JavaScript (ES6+)
- CSS3 (Flexbox & Grid)
- Vite
